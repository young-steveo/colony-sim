# Painter's Palette — design exploration (Claude Design, July 2026)

Reference bundle from the claude.ai/design exploration commissioned via
`docs/palette-ui-brief.md`. The spec (`Painters Palette Spec.dc.html`,
sheets 01–04: foundations, palette bar, cursors/motion, secondary
surfaces) is the deliverable of record; the `assets/` pngs are the
designer's pixel *specimens* — reference for Stephen's art and for
implementation, not runtime assets. The in-game palette
(`game/palette_bar.gd`) implements the foundations programmatically;
runtime art stays in `content/`.

Omitted on purpose: `assets/scene.png` (a mocked world screenshot used
as page dressing in the spec — no reference value; the real game
exists). View it in the design project if ever needed.
